# React + Vite + TypeScript

Projeto inicial criado com Vite, React e TypeScript.

Pré-requisitos
- Node.js (>=16)
- npm (ou pnpm/yarn se preferir)

Instalação (PowerShell)

```powershell
npm install
npm run dev
```

Scripts disponíveis
- `npm run dev` — roda o servidor de desenvolvimento (Vite)
- `npm run build` — gera a build otimizada em `dist/`
- `npm run preview` — pré-visualiza a build gerada
- `npm run type-check` — executa o TypeScript type-check (sem emitir arquivos)

Notas
- As dependências estão listadas em `package.json`. Depois de instalar, abra o navegador na URL que o Vite exibir (por padrão `http://localhost:5173`).
- Para trocar o gerenciador de pacotes (pnpm/yarn), substitua os comandos de instalação e execução conforme apropriado.
